Telecomunicacions

La tecnologia que permet transmetre informació a distància.

Què són les telecomunicacions?

Les telecomunicacions són el conjunt de tècniques i sistemes que fan possible enviar veu, dades, text, imatges i vídeo entre persones o dispositius, encara que estiguin situats en llocs diferents.

Tipus de xarxes

  • LAN: connecta dispositius dins d’un espai reduït, com una casa o una escola.
  • MAN: cobreix una ciutat o una àrea metropolitana.
  • WAN: connecta xarxes a grans distàncies; Internet n’és l’exemple més conegut.
  • Xarxes mòbils: permeten comunicar-se mitjançant tecnologies com el 4G i el 5G.

Elements principals

  1. Emissor: origina el missatge.
  2. Canal: transporta la informació, per exemple la fibra òptica o les ones de ràdio.
  3. Receptor: rep i interpreta el missatge.
  4. Protocol: estableix les normes perquè la comunicació sigui correcta.

Aplicacions quotidianes

Les telecomunicacions són presents en les trucades telefòniques, les videoconferències, la televisió, la ràdio, el correu electrònic, les xarxes socials, la telemedicina i els serveis al núvol.

Importància i reptes

Aquest sector facilita l’accés a la informació, l’educació i el treball a distància. Alhora, cal garantir la seguretat de les dades, la privacitat, la cobertura universal i un consum energètic responsable.
